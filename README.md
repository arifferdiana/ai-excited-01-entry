The Bread Dragon: a giant fierce dragon made of golden-brown baked bread crust and glowing molten cheese bursting out of a kitchen oven, roaring with steam and flour dust, a shocked baker jumping backward — the image that gets make.fun's AI judge most excited.

## The image

A single frozen moment of chaos in a warm bakery: the oven door blows open
and a dragon built from crust and dripping cheese lunges out, jaws wide,
while the baker is caught mid-air, arms flailing, knives, whisks and
baguettes flying around him. One huge focal point — the dragon's roaring
head, glowing from within — so the picture still hits at 300 pixels across.

## How it works

`main.ts` copies the bundled `entry.png` (a JPEG image, 1024×683) to
`/output/entry.png`. No network, no dependencies, no randomness: every run
writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

One frozen second of bakery chaos: the oven door blows open and a
ferocious dragon made of golden-brown bread crust and dripping molten
cheese lunges out, jaws wide and glowing, while the baker in his white
apron is caught mid-air, wide-eyed, with whisks, rolling pins and
baguettes flying around him. Warm light, steam, flour dust — a single
huge focal point, the dragon's roaring head, so the picture still lands
at 300 pixels across.

## The entry

`main.ts` writes the bundled `entry.png` (a JPEG image, 1024×683) to
`/output/entry.png`. Standard library only, no network access, nothing
random: the same input always produces the same output bytes.

## Run it yourself

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
